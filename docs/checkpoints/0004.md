## Completed since checkpoint 0003

Added a lightweight local graphical interface, embedded in the Rust binary and served by Axum 0.8.9 on 127.0.0.1. It provides saved stories, new story, narration/dialogue/choices, typed actions, illustrations, progress/cancel, story journal, model/image settings, export, lore/director notes and reference attachment. A localhost browser interface meets the basic GUI requirement without the larger Tauri packaging toolchain; this is not a native Tauri app.

The private API requires a random session capability; cross-origin mutations are rejected. The launch fragment is removed from the address bar and held in browser session storage. data/ui-session.json is mode 0600 and must stay out of source archives/cloud worklogs. API images are fetched with authorization and shown through local blob URLs. JavaScript inserts model text as text, not executable markup.

Expected-turn checks now run inside the database turn lease for story and image operations, rejecting stale displayed choices before inference and preventing illustrations from attaching to a changed turn. Job cancellation aborts the model future and its process group. Interrupted-attempt recovery acquires the turn lease before changing statuses, preserving concurrent CLI work.

GameState now has backward-compatible, application-owned lorebook and director_note fields. Retrieval adds up to four relevant bounded notes. Recent context also includes at most two dialogue lines from each of the last two scenes, retaining concrete names without passing the whole transcript. The system prompt asks for concrete discoveries, concise dialogue and durable exact facts. The revised prompt has not yet been exercised with a real model.

Reference upload resizes a user picture to at most 1536 pixels, saves a new PNG and associates it with a known canonical character/location. The image backend supports one composition reference through img2img; this does not prove identity conditioning or lock a face. Real reference generation remains to be tested.
